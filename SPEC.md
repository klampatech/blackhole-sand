# Blackhole Sand

A 2D particle-physics engine for space, where celestial bodies are made of
particles and a black hole's tidal forces can rip them apart particle by
particle.

**Canonical spec:** [`docs/SPEC.md`](docs/SPEC.md). This file is a stub pointer —
all design, decisions, and architecture live in `docs/SPEC.md`. Edit that file
on a branch + PR.

## Quick start (when Phase 1 lands)

```bash
cargo run
```
